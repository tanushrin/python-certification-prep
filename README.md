- **Level**: Entry

### PCAP - Certified Associate in Python Programming  
- **Level**: Intermediate

- **Content**: [Certs/PCAP/](Certs/PCAP/)

## 🚀 Getting Started

### Prerequisites
- Python 3.8 or higher
- Git
- VS Code (recommended) or your preferred code editor

### Setup Development Environment

1. **Clone the repository**
   ```bash
   git clone https://github.com/tanushrin/python-certification-prep.git
   cd python-certification-prep
   ```

2. **Install dependencies**
   ```bash
   pip install -r requirements.txt
   ```

3. **Open in VS Code**
   ```bash
   code .
   ```
   The repository includes VS Code configurations for optimal Python development experience.

4. **Start Jupyter Lab (for interactive notebooks)**
   ```bash
   jupyter lab
   ```
